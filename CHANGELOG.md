# Changelog

All notable changes to `tygr-uri` are documented here.

## [0.1.0] - Unreleased

The URI syntax of RFC 3986 as tygr 0.9 types: each rule of its Appendix A is
a type that parses and prints its text. Four rules are written differently
from the RFC's ABNF, each matching the same text: `dec-octet`, `path`,
`IPv6address` and `host`. The README says how and why.
